# Roadmap

These ideas are **planned**, not advertised as available:

- Better multi-page PDF pagination and optional logo uploads.
- Multi-proposal dashboard with opt-in encrypted local backups.
- More locale-aware date and currency presentation.
- Keyboard shortcuts, accessibility audits, and visual regression testing.
- Reusable scopes and checklists for different professions.
- Independent verification of the production website across desktop and mobile browsers.

Feature requests should describe a real user workflow. Avoid adding accounts, trackers, or complexity without a clear benefit.
